# Contributing Guide

Thanks for your interest in ClipBridge! Issues and Pull Requests are welcome.

English | [中文](CONTRIBUTING.md)

## How to Contribute

1. **Fork the repository**
   - Click the Fork button in the upper right corner
   - Create a feature branch in your own fork

2. **Open an Issue**
   - Clearly describe the problem or suggestion
   - For bugs, provide reproduction steps and system environment

3. **Submit a Pull Request**
   - Make sure the code compiles
   - Keep the coding style consistent with the existing codebase
   - Explain the changes in the PR description

## Development Workflow

### Branch Strategy

- `qt`: main branch for the Qt cross-platform version
- `master`: main branch for the native Windows version
- Feature branches: `feature/your-feature-name`
- Bug fix branches: `fix/issue-description`

### Code Style

- Follow the existing code style of the project
- Keep comments concise and clear
- Add necessary documentation/explanation for new features

### Commit Messages

Commit messages should clearly describe the change:

```
feat: add a new feature
fix: fix a bug
docs: update documentation
refactor: refactor code
style: formatting changes
```

## Notes

- Do not commit files unrelated to the feature
- Keep the commit history clean
- Large changes are best discussed in an Issue first

## Code of Conduct

- Respect every contributor
- Keep discussions friendly and constructive
- Focus on the technology itself

Thank you for contributing!
