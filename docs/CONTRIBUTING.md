# 贡献指南

感谢你对 ClipBridge 的兴趣！欢迎提交 Issue 和 Pull Request。

## 如何贡献

1. **Fork 仓库**
   - 点击右上角的 Fork 按钮
   - 在你的仓库里创建功能分支

2. **提交 Issue**
   - 描述清楚问题或建议
   - 如果是 Bug，提供复现步骤和系统环境

3. **提交 Pull Request**
   - 确保代码可以编译通过
   - 保持代码风格一致
   - 在 PR 描述里说明改动内容

## 开发流程

### 分支策略

- `qt`：Qt 跨平台版本主分支
- `master`：Windows 原生版本主分支
- 功能分支：`feature/your-feature-name`
- Bug 修复分支：`fix/issue-description`

### 代码规范

- 使用项目现有的代码风格
- 保持注释简洁清晰
- 新功能请添加必要的说明

### 提交信息

提交信息应清晰说明改动：

```
feat: 添加新功能
fix: 修复某个 Bug
docs: 更新文档
refactor: 重构代码
style: 代码格式调整
```

## 注意事项

- 不要提交与功能无关的文件
- 保持提交历史整洁
- 大型改动建议先在 Issue 中讨论

## 行为准则

- 尊重每一位贡献者
- 保持友善和建设性的讨论
- 专注于技术本身

感谢你的贡献！
